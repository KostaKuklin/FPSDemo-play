# Neon Oni: play in the browser

https://kostakuklin.github.io/FPSDemo-play/

A first-person arena roguelike prototype: throw daggers at swarms of
tsuchigumo spawn, collect yen and XP, offer yen at shrine boxes for omamori
items. Built in Godot 4.7. This repo only holds the built game and is
replaced on every deploy.

Click the game to lock the mouse (click again after Esc or switching tabs).
Controls: mouse aim · LMB throw · RMB bind (Chain dagger) · WASD move ·
Shift dash · Space jump · E offer · Q usable item · Tab run and items ·
R reload · Esc pause and tuning.

On a phone or tablet (hold it sideways): left thumb moves, drag on the right
to look, and the on-screen buttons do the rest.
